Configurar o Assistente

Usa a IA gratuita do Groq. Crie a chave em console.groq.com → API Keys → Create API Key e cole abaixo. Ela fica guardada criptografada neste PC.

Avisos no celular

O painel manda notificação pelo ntfy (o mesmo app do Dito Feito). No app, toque em + e assine o tópico abaixo.
Quem souber o nome do tópico recebe os avisos. Use um nome difícil, só seu.

Adicionar máquina

Digite o IP da máquina nova. O painel confere se ela está pronta, coloca na lista e deixa igual às outras.
A máquina ainda não foi preparada? Veja como
  1. Na máquina nova, entre com a conta de administrador dela.
  2. Clique com o botão direito no Iniciar e abra Terminal (Admin) ou PowerShell (Admin).
  3. Cole o comando abaixo e aperte Enter. Quando pedir, use a mesma senha do CRJ-Admin das outras máquinas.
  4. Quando terminar, volte aqui e clique em Verificar.
irm http://192.168.10.124:8000/preparar-pc.ps1 | iex
